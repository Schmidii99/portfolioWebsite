This was the last project in the first semester of my Computer Science studies and was created in collaboration with Lorenz
Schmid. The full documentation (in german) can be downloaded in a Word document, [here](https://github.com/Schmidii99/TrainingsDiary/raw/refs/heads/main/src/Demo.docx).

We used the Java programming language as well as a PostgreSQL database in the backend. The program is a simple console
application. I am especially proud on my [menu class](https://github.com/Schmidii99/TrainingsDiary/blob/main/src/tools/Menu.java) 
that can be dynamically expanded and uses lambdas.
